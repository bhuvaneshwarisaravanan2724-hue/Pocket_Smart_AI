# Pocket Smart AI

Pocket Smart AI is a smart budget and recommendations assistant.

## Features

- User registration and login
- Expense tracking
- Budget calculation
- AI-powered budget recommendations
- Home planner
- Party planner
- Jewelry planner

## Technologies

- Python
- FastAPI
- SQLite
- SQLAlchemy
- Jinja2
- Google Gemini AI

## How to Run

Activate the virtual environment and start the FastAPI server:

```bash
uvicorn app.main:app --reload
